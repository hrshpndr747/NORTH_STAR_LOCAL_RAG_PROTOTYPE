NORTHSTAR RAG DUMMY DATASET - QUICK START

This bundle contains entirely fictional data. It is safe for learning and demonstration, but it must not be presented as a real company policy.

FASTEST CONFLUENCE CLOUD SETUP

1. Create or open a private test space in Confluence Cloud.
2. Select Create to open a blank page.
3. Before typing, open More actions (...) and choose Templates and import.
4. Open the Import tab and choose Word document (.docx).
5. Select all 10 files inside 01_Confluence_Pages and import them together.
6. Confluence should place them under a restricted Imported pages parent. Review, publish, and move them as needed.
7. Create a page named Dataset Attachments.
8. Drag the two PDFs, Remote Work Equipment Standard DOCX, the XLSX workbook, the MP4 video, and the VTT transcript from 02_Attachments onto that page.
9. Keep support_operations.db local for SQL testing; attaching it to Confluence is optional and Confluence will not query it as a live database.
10. Use the 30 questions in 03_Evaluation to test retrieval, citations, spreadsheet querying, SQL querying, and refusal behavior.
